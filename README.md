# HTML Tycoon

A web-based idle game where you manage your own web development empire. Build websites, gain reputation, research new technologies, and become the ultimate web development tycoon!

## Features

- Build and manage various types of websites
- Earn money and reputation
- Research new technologies
- Upgrade your infrastructure
- Real-time resource management
- Save game progress automatically

## Getting Started

1. Install dependencies:
\`\`\`bash
npm install
\`\`\`

2. Start the development server:
\`\`\`bash
npm run dev
\`\`\`

3. Build for production:
\`\`\`bash
npm run build
\`\`\`

## Technologies Used

- React
- Vite
- Zustand for state management
- CSS3 for styling
